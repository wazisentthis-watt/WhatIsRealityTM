# YOUR · One MELLA, Every Reality (playable vertical slice)

**Version:** 0.1 preview, 2026-11-15. **NOT CANON.** This is a static, source-visible mini-game with one shared local MELLA identity, progress and append-only event ledger. Play `index.html` locally or deploy this directory to a static host. The 85 legacy WIR games are **not** merged.

## Actual gameplay

- **Valence Life:** move in the neighborhood, work for electrons, recover energy at home, walk through portals.
- **WishBorn:** plant, water and harvest a DreamSeed; progress persists between sections.
- **KoPani:** meet Na and offer DreamSeeds to build persistent trust.
- **Gridiron:** time the football catch to win a three-catch practice series.
- **Metal:** approach a training drone and strike on the rhythm window; vertical knockback has gravity and a guaranteed landing.
- **GHOULIE, Worldbuilder, Reality Arcade:** registered navigation doors only, openly not imported.

## Source and privacy

Design informed by owner-provided `WIR Valence Life.zip` (34,763,863 bytes), `VALENCE_LIFE_COMPLETE_GAME_v04_SOURCE_SPRITES_LOGIC.zip` (13,321,260 bytes), [WIR shared protocol](https://github.com/wazisentthis-watt/wir-100-studio/blob/main/WIR-PROTOCOL.md), [Octec contracts](https://github.com/wazisentthis-watt/wir-100-studio/blob/main/octec/engine/CONTRACTS.md), and [Octec registry](https://github.com/wazisentthis-watt/wir-100-studio/blob/main/octec/BRANTACLES.json). These are **design references**, not claims that their complete original source is already ported. Private Drive ZIPs, original artwork, roster data, property records and private source code are not shipped in this public preview.

One browser / one device: key `wir.your.vertical.v1`; schema `wir.your.slice.v0.1`. It is **not** the final `wir.octec.save.v1` schema. Export and import are supported. No cloud sync. Event names follow the shared WIR protocol vocabulary; event entries are local, not verified server events. No account auth, payments, analytics, private records or real estate data.

## Controls and QA

Move: WASD / arrows, mobile pad or gamepad left stick. Interact: E, touch button, or gamepad A. Run `node --test your/smoke.test.mjs` from the repository root to check syntax and source-level contracts. Browser/device, saves and controller behavior still require hands-on QA before promotion.

## Promotion gate

Before integrating any full WIR source: compare versions, verify provenance/license, migrate to Octec namespaced section state, test round-trip across worlds, back up old saves, run touch/gamepad tests, then request owner approval. Source Siphon / private studio stays under **PROPOSAL / PUBLISH HOLD**. This public website is a separately authorized, uncanonical preview.
